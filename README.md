# Gator

Gator is a command-line RSS feed aggregator built with TypeScript, Node.js, PostgreSQL, and Drizzle ORM.

It allows users to register, follow RSS feeds, periodically collect posts from those feeds, and browse the latest posts directly from the terminal.

## Requirements

Before running Gator, make sure you have:

- Node.js
- npm
- PostgreSQL
- Git

You can check your Node.js version with:

```bash
node --version
